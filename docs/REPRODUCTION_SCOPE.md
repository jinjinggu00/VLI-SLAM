# 当前运行接口与范围

## 已提供的独立接口

```text
bootstrap.py image    -> 显示或获取公开固定Docker镜像
bootstrap.py models   -> 获取/核对原作者预训练模型
bootstrap.py source   -> 获取/核对固定commit的上游源码
bootstrap.py bags     -> 只读核对两份输入的ROS1 bag V2文件头
```

这些接口不依赖私有数据包、场景缓存或参考结果。它们不等同于原始bag完整SLAM执行，也不会计算ATE、RTE、AUC或声称得到官方成绩。

## 目标完整流水线

```text
使用者提供的原始双场景bag + 官方标定配置
  -> 消息解码、时间与单位处理、鱼眼双目重映射
  -> AirSLAM点线视觉惯性估计 + 原生局部/全局BA
  -> 点云/Point-LIO运动约束
  -> BoQ候选 + ALIKED/LightGlue对应 + DepthRegister激光深度
  -> Kabsch与双向PnP验证、观测筛选
  -> g2o机器人位姿与共享三维点联合优化
  -> 两场景TUM轨迹与可选地图
```

当前未发布可独立运行上述全部阶段的统一入口。保留的`adapter_sources/`依赖历史工程中的准备模块、运动约束生成器、原生地图构建及运行依赖；仅改变一个WORKSPACE变量不足以解除这些依赖。

后续完整入口必须重新生成中间观测与地图，不能从旧最佳提交包、封存轨迹、既有图像/点云缓存读取它们来替代从头运行。算法和参数的任何变动都需明确记录，不能把新流程的输出默认为历史官方评分结果。

## 历史后端接口

`run_joint.sh`重编译最终g2o桥接并求解冻结联合图，要求用户已有完全匹配的历史输入；本仓库不提供这些输入。其成功复现只能证明同一冻结输入上的后端重编译与求解一致，不能证明原始bag前端、深度、回环与GBA已重新执行。

`docs/LEGACY_BACKEND.md`保留原使用说明，仅供已经拥有对应完整历史工程的使用者参考。新的依赖准备路径不要求获取该历史压缩包。
